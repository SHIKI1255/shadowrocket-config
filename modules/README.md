## 安装、手机更新与回退

1. 备份手机配置和已有手动映射，保留备用节点。
2. 清理或停用主配置及其他模块中的同名映射，避免旧记录掩盖效果。
3. 在 Shadowrocket **模块管理**中下载并启用上述地址。已有模块直接刷新，不重复导入，也不当作完整配置或节点订阅导入。
4. 保留原始订阅节点的域名、端口、密码和 UDP 设置；断开后重新连接，必要时清理 DNS 缓存。
5. 核对节点实际连接的入口 IP 与上表一致，测试网页、其他 GeekSpeed 节点及雪橇云。入口 IP 与出口 IP 不同。

安装不需要 HTTPS 解密或证书。用户此前已验证手动 BGP Hosts 有效，并反馈使用正常；该历史反馈不代表后来变化的新 IP 已经通过手机验收。
优先测试当前在用入口及原订阅更新后的效果；不为复现故障故意修改节点。模块后台刷新能力与实际刷新时间仍需手机验收。

停用模块可恢复原解析行为，也可能恢复原始故障。恢复可用状态应使用已验证的固定版本或旧手动映射，并停用重复来源。
每次变化的快照区保留上一版固定提交链接。服务端回退通过新提交恢复内容，保留历史；旧 IP 是否仍由服务商提供不能保证。
只有确认模块不能影响节点入口解析且已排除缓存、重复记录后，才另行评估迁入主配置现有 `[Host]`；本任务不自动修改主配置。

## 本机自动维护

`GeekSpeed-Hosts.sgmodule` 是唯一生效文件，直接由 `main` 分发，不进入 `release` 或公共规则生成器。
机场订阅更新、GitHub 模块发布、手机刷新是三个独立环节；手机仍由使用者手动刷新。

部署目标：每天北京时间 **09:00** 的独立本机任务，模型 **GPT-6 Luna**、推理 **high**。实际启用状态、运行及异常查看应用的任务记录。
电脑须开机、应用须运行；不承诺离线时执行或补跑。任务执行固定程序，不自行修改脚本、调整门槛或手工挑选 IP。

### 同步规则

- 仅从已核实的本机 GeekSpeed 订阅索引读取地址，使用 `Clash.Meta` 拉取 HTTPS YAML；不改写本机订阅缓存。
- 严格检查来源、重复键、空集合、精确域名、单值公网 IP；拒绝别名、通配符、额外模块段和无法无损转换的记录。
- 有变化时等待 10 秒再读取，要求两次完整 Hosts 一致。新增、删除、全部 IP 更换均可同步，不保留服务商已删除项。
- PR 检查通过后、合并前再次读取服务商，完整映射必须仍与候选一致；变化或读取失败时保留旧模块和待处理 PR，不持续请求直到匹配。
- 一致性按规范化后的完整域名到 IP 集合核对；域名大小写、末尾点、等价 IPv6 表示可规范化，不合并重复域名或丢弃无法转换的记录。只能确认发布前最后一次成功响应，不能保证发布后服务商不再变更。
- 新数量 ≤ 原数量一半，或 ≥ 原数量两倍时暂停。门槛随已发布条数变化；例如基线 17 条时，8 条及以下或 34 条及以上需人工处理。
- 映射内容不变时不提交；顺序、节点数量及日期变化不单独提交。保留原有条目顺序，新增项按源顺序追加。
- 映射变化时在模块现有 `#!desc` 末尾写入 `；Hosts 内容更新时间：YYYY-MM-DD HH:mm:ss +08:00`，说明快照使用同一时间。它是该版来源确认、生成候选的北京时间，不是服务商修改时间或 GitHub 合并时间。
- 时间只保留最新一条，随真实变更替换；无变化、重试及发布读回不刷新时间。现有无时间模块继续兼容，首次升级无映射变化时不为补时间单独提交。
- 下载超时 25 秒、最大 10 MiB；临时错误最多 3 次，认证失败和格式错误不反复重试，拒绝重定向。

### 本机程序

公共规则构建和模块格式校验仍仅用 Python 3.12 标准库。
同步器额外依赖已安装的 `PyYAML==6.0.3`；本机缺失或版本不同则报告，不自动安装、升级或降级。
GitHub 使用本机已有 `gh` 登录。运行前对照已发布程序版本；代码更新后应人工同步本机源码，不自动执行下载的程序。

从仓库目录在 PowerShell 7 中调用，`<state-directory>` 必须是已登记的仓库外本机输出目录：

```powershell
python -B scripts/sync_hosts.py --check --state-dir <state-directory>
python -B scripts/sync_hosts.py --publish --state-dir <state-directory>
python -B scripts/validate_hosts.py
```

`--check` 拉取并报告脱敏差异，不创建 PR；`--publish` 才允许发布。
输出状态为 `unchanged`、`candidate`、`pr_created`、`published`、`needs_attention` 或 `failed`。
异常退出码为 1，不得把失败当作无变化。仅异常通知，成功及无变化保留任务运行记录。

### 发布保护

只允许更新模块和本说明，且说明只改快照区。先创建限定两文件的 PR，通过专门 Hosts CI 后再合并。
合并使用已验证 PR 的完整文件树，通过非强制快进保护 `main`；出现并发提交即停止，不强推或恢复机场规则。
仅模块变化不触发业务规则重建；原有业务规则日更保持独立。
修改发布工作流自身必须执行完整联网构建和离线复现；混合修改 Hosts 与公共规则时两套检查都要执行。

互斥锁防止重叠执行。已有同步 PR 或未完成发布时，不创建第二个 PR。
CI 失败或超时留下 PR 并通知，等待人工处理；程序不会在后续任务中自动合并过期候选。
合并后分别匿名校验固定提交和滚动 Raw 地址的模块与说明哈希；PR 状态或缓存短暂延迟时，仅对读回核验最多尝试 3 次，间隔 5 秒、10 秒。仍未确认则保留待核验状态，不重复发布或自动回滚。
恢复未完成读回时，输出 `verification_only: true`，仅表示旧发布核验完成，不表示重新核对过当日服务商响应；下一轮正常任务才会重新拉取。不得借恢复流程合并过期候选。
状态目录仅保存公开的提交、PR 和哈希。失败后先检查任务原因及对应 PR；若需重试未合并候选，人工处理旧 PR 和状态后重新读取订阅，不能绕过校验。

### 隐私边界

订阅地址、凭据及完整响应只在本机内存中处理，不进入模型上下文、命令行参数、GitHub、附件、缓存或日志。
不向 GitHub 添加机场 Secret；GitHub CI 只使用虚构订阅测试数据。公开内容只包含 Hosts、引用数量和必要说明。
错误只输出预定义原因，不直接输出底层异常、响应片段或堆栈。
